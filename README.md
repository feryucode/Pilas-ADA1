# Pilas-ADA1
Este repositorio contiene los dos programas solicitados para la tarea sobre el uso de la estructura de datos Pila (Stack).

Archivos incluidos

evaluador_pila.py: Programa que evalúa expresiones aritméticas en notación posfija y prefija apoyándose en una pila.

historial_navegador.py: Programa que simula el historial de sitios visitados en un navegador web (agregar páginas, regresar a la anterior y ver el historial) usando la clase Pila.
